#### Create CodeCommit Repository

1. Go to [CodeCommit service administration interface](https://console.aws.amazon.com/codesuite/codecommit/home).

    + Switch **Region** to **Region** you use for practice.
    + Click **Create repository**.


![Cloud9](/images/2-Prerequiste/2.1-cloud9/00010.png?featherlight=false&width=90pc)

2. On the Create repository page.

   + In the **Repository name** section, enter **theme-park-frontend**.
   + Click **Create**.

![Cloud9](/images/2-Prerequiste/2.1-cloud9/00011.png?featherlight=false&width=90pc)

3. Make sure your Repository is created successfully.

![Cloud9](/images/2-Prerequiste/2.1-cloud9/00012.png?featherlight=false&width=90pc)

Next, we will proceed to deploy the sample application to AWS.
