#### Check features

1. Select the trip profile from the map

+ Select **Add ride photo**

![Cloud9](/images/2-Prerequiste/2.1-cloud9/000117.png?featherlight=false&width=90pc)

2. Select an image to check and **add**

![Cloud9](/images/2-Prerequiste/2.1-cloud9/000121.png?featherlight=false&width=30pc)

3. Wait about 30 seconds, and **Photo processed** will appear, select **OK**

![Cloud9](/images/2-Prerequiste/2.1-cloud9/000118.png?featherlight=false&width=90pc)

4. Access to **S3**

+ Select **theme-park-backed-finalbucket-xxx**
+ Select the returned image, then select **Download**

![Cloud9](/images/2-Prerequiste/2.1-cloud9/000119.png?featherlight=false&width=90pc)

5. Return image results.

![Cloud9](/images/2-Prerequiste/2.1-cloud9/000122.png?featherlight=false&width=30pc)

6. Continue experimenting with the images you want.

![Cloud9](/images/2-Prerequiste/2.1-cloud9/000120.png?featherlight=false&width=30pc)
